Como o simulador funciona por dentro

O programa foi dividido em partes independentes: o núcleo só cuida da lógica do autômato (não sabe nada de tela), e a interface só desenha o que o núcleo devolve. Abaixo estão os trechos mais importantes, tirados do código real.

js/automato.jsNúcleo: valida o JSON e simula a palavra.
js/app.jsInterface: desenho em SVG, fita, botões.
exemplos/*.jsonAutômatos de exemplo.
tools/test.js231 testes automáticos.

O formato do arquivo JSON

Cada campo corresponde a uma das cinco partes de um autômato: estados (Q), alfabeto (Σ), transicoes (δ), estadoInicial (q₀) e estadosFinais (F). Em transicoes, cada símbolo leva a um único estado (texto, não lista).

Testes automáticos

O arquivo tools/test.js roda 231 verificações, incluindo o AFD de múltiplo de 3 conferido contra a conta real (n % 3) para todos os números de 0 a 200, a catraca, a palavra vazia, os símbolos inválidos, o AFD que trava e os arquivos inválidos.
